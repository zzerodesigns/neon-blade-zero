ZeroG v0.0.3 • Zero-Allocation Web Engine Specification

Architectural Standards & Principles

The definitive engineering standard for high-performance, single-file, zero-allocation web applications and game simulations. Guaranteed 60–240 FPS frame pacing, zero GC pauses, and zero asset overhead.

The Golden Rule
If a variable, vector, buffer, container, sound, or mesh is needed during runtime, it must exist before the first frame runs. The animation loop only mutates; it never creates.

Zero GC Hot Paths HOT
No object/array construction in ticks. Module-level scratchpad registers (_V1, _M1) handle transient math. Swap-and-pop arrays eliminate splice overhead.
Dual Kinematic Paradigms PHYS
Fixed timestep with state interpolation for rigid bodies, or adaptive displacement-clamped substepping for fast-paced responsive parkour and movement.
3D Prime Spatial Grid O(1)
Bitwise prime hashing maps 3D volumetric coordinates to flat 32-bit array buckets with zero string allocations and zero Map iterator churn.
Zero-Asset Procedural Audio AUDIO
Web Audio oscillators and pre-allocated cyclic noise buffers synthesize all sound effects. First-gesture unlock ensures immediate audio playback.
Zero-Layout-Thrashing DOM DOM
Quantized, dirty-checked HUD updates prevent layout thrashing. GPU-composited transforms (translate3d, opacity) avoid reflow penalties.
Unidirectional Topology SYS
State flows in a strict pipeline: Inputs → Kinematics → Spatial Grid → Entities → Audio → Camera Decoupling → GPU Render.

1. Zero Garbage Collection Mandate

In high-frequency loops (60–240 FPS), memory allocations trigger garbage collection spikes. Objects created inside update functions are immediately discarded, forcing the engine into unpredictable freeze frames. 

// Pre-allocated math registers at module scope (allocated once at boot):
const _V1 = new THREE.Vector3();
const _V2 = new THREE.Vector3();

// Inside hot loop (animate / physicsStep):
_V1.copy(player.position).addScaledVector(_V2, dt);

// Result: Zero heap allocations, zero GC pauses.

2. Single-File Integrity

The entire application is completely portable. It does not rely on an external bundler runtime, nested source files, or separate assets. Opening index.html directly serves the complete, functional application with zero setup and zero missing dependencies.

3. Procedural Sound & GPU Visuals

Web Audio API nodes (oscillators, biquad filters, gain envelopes, cyclic noise buffers) synthesize laser blasts, impacts, and ambient drones mathematically. World-space triplanar shaders render scale-invariant borders and procedural surfaces directly on the GPU.
